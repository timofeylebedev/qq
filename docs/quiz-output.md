# What every answer of the quiz gives

Written by `build/quiz.mjs` (`npm run quiz`) from `data/quiz.json`, the catalogue's methods and map and the taste model. Do not edit: change the data or the rules and rebuild. How it works: `docs/quiz.md`.

675 answer sets (9 methods × 3 × 5 × 5). «Не знаю» for the taste gives three different coffees (marked ≠); otherwise the first coffee, then two moves away from it. The move's source: page = the coffee page's «Что взять еще», model = the taste model's direction, region = the best in the visitor's region.
