# What each coffee's page offers next

Written by `build/taste.mjs` (`npm run taste`): the block on every coffee's page, from the taste model. Do not edit. How the moves are chosen: `docs/taste-model.md`, «The block on a coffee's page».

Edges said in words: softer 5, brighter 2, unusual 0, classic 0, similar 0; «под молоко» is this coffee itself on 10; two moves share a card on 2; far picks 10.
